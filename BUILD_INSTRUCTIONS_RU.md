# Earshot Sony ANC — сборка APK

1. Создайте новый **приватный** репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория (включая скрытую `.github`). Можно использовать Add file → Upload files. Для большого числа файлов удобнее GitHub Desktop или git.
3. Откройте Actions → Build Sony ANC APK → Run workflow.
4. После успешной сборки откройте её страницу и скачайте артефакт `Earshot-Sony-ANC-APK`.
5. Распакуйте ZIP артефакта и установите APK на телефон. Разрешите установку из этого источника, если Android запросит.

Это отладочная сборка с подписью GitHub runner. При повторной сборке подпись может измениться, поэтому обновление поверх ранее установленной сборки может не сработать. Приложение может конфликтовать с установленным Earshot по идентификатору пакета; при конфликте потребуется удалить старое приложение, предварительно сохранив нужные настройки.

Режимы сопоставляются по смыслу QUIET/AWARE/OFF, а не по жёстко заданным номерам. Отображение диалога поверх шторки зависит от OriginOS 7 и требует проверки на телефоне.
